# Standard Algorithm: Subtraction

An interactive for the standard subtraction algorithm with two- and three-digit numbers. Students drag the numbers into place (the bigger number goes on top), subtract one column at a time, and regroup by tapping the digit to the left: the digit is crossed out, a small box holds the new digit, and a small box with a 1 shows the ten that moved over.

Open `index.html` in a browser, no build step needed.
